Before we look at anything: one question that will save a lot of time.

**Is this test failing because the code is wrong, or because the test is wrong?**

This isn't rhetorical. Both happen constantly — and the answer changes everything about where you look. "Only fails in CI" is a clue, not an explanation. Before you tell me about the error itself, can you say which it is — and why you think so?

---

Once you've answered that, I want you to do three things with the error before we discuss anything:

**Gate 1 — What is the error type?**

What type of error is this — and what does that type tell you about what went wrong?

Not the full stack trace yet. Just the error type, and what you think it means about the category of failure you're looking at.
